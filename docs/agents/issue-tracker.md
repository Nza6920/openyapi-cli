# Issue tracker: GitHub

Issues and specs for this repo live as GitHub issues. Use the `gh` CLI for all operations.

## Conventions

- Create, read, list, comment on, label, and close issues with `gh issue`.
- Infer the repository from the GitHub `origin` remote.
- Pull requests are not a triage request surface.
- Specs and tickets are published as GitHub issues.
- Use native GitHub issue dependencies when available; otherwise record `Blocked by: #<n>` in the issue body.
